# 📝 Todo List Web Application

A simple and interactive **Todo List Web App** built using **HTML, CSS, and JavaScript**.
This application helps users manage daily tasks efficiently with a clean UI and smooth functionality.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* ❌ Delete tasks
* 🔍 Search tasks in real time
* 💾 Tasks saved using **Local Storage**
* 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

* **HTML** – Structure
* **CSS** – Styling & layout
* **JavaScript** – Logic, DOM manipulation & Local Storage

## 📂 Project Structure

todo-list
├── index.html

## 🚀 How to Run the Project

1. Clone the repository
   ```bash
   git clone https://github.com/Zehara-K/todo-list.git
   ```
2. Open the project folder
3. Open `index.html` in your browser
✅ No additional setup required.
